# shared

此模块存放不拥有连接生命周期的基础契约：公开类型、稳定错误码、默认值、字节估算和结构化克隆校验。

同步外部回调隔离和有总期限的准备事务也在这里复用；未结算任务额度按 realm 计，不持有连接池。错误只有库拥有的 code/message/fatal/retryable，克隆估算包含 backing buffer 并拒绝 accessor、共享 buffer 与无界图。

它不得依赖 core 的其他功能目录。上层模块可以依赖它，但必须保留这里定义的单位、错误脱敏与可克隆性约束。

没有独立 npm 入口；应用代码通过 `socketfuse` 的类型与错误导出使用这些契约。
