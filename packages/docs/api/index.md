# API reference

The API reference is generated by TypeDoc from the three public package entry
points on every docs build. It is not hand-maintained.

- [`wws`](./generated/index/README.md) — `createWebSocket`, clients, options and errors.
- [`wws/protocol`](./generated/protocol/README.md) — raw protocol and adapter types.
- [`wws/worker`](./generated/worker/README.md) — custom Worker runtime entry.

For usage guidance, begin with [Getting started](../guide/getting-started) and
use the generated entries for exact type shapes.
